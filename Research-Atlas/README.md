**Forge date:** 22 August 2026

**Mode:** Preservation-first, additive, openly speculative
**Purpose:** Recover the archive's latent theories, research questions, spiritual lenses, dream material, and worldbuilding without confusing imagination with evidence.

## Start here

This directory is a map laid over the raw archive, not a replacement for it. AURA began as a constitutional AI framework and grew outward into LAMAGUE, CASCADE, AURA Prime, MicroorciM, dream-consciousness notes, spiritual experiments, symbolic mathematics, speculative physics, and the Sovereign 36 mythic cycle. Those layers can coexist if their epistemic status stays visible.

The atlas therefore keeps two promises at once:

1. **Nothing imaginative is discarded merely because it is unproven.** Unusual ideas can remain as hypotheses, conceptual probes, symbolic art, or fictional canon.
2. **Nothing is promoted to science merely because it uses equations or scientific language.** Equations define a model; evidence determines whether the model describes reality.

The shortest honest description of AURA remains:

> A self-referential knowledge architecture for human-AI coherence. Its function is coherence, not proof of consciousness.

The future research programme built from this preserved map now lives in the [`AURA Frontier Compendium`](../Frontier-Compendium/README.md). The compendium is downstream interpretation; this atlas remains its recoverable ancestry.

## Epistemic status legend

Every substantive branch should carry one or more labels.

| Label | Meaning |
|---|---|
| `[CORE]` | Canonical to the minimal AURA architecture: the Tri-Axial metrics and Vector Inversion. This means “core to this project,” not “scientifically proven.” |
| `[IMPLEMENTED]` | Some code, parser, model, or demonstration exists in the repository. Implementation is not external validation. |
| `[TESTABLE]` | Variables, predictions, and failure conditions can be specified now. |
| `[RESEARCH-ADJACENT]` | A real research field touches the idea, but the AURA claim is not established by that research. |
| `[SPECULATIVE]` | A scientific-style conjecture with no confirming evidence in the repository. |
| `[SYMBOLIC]` | A psychological, philosophical, artistic, or spiritual interpretation. It may be useful without being a literal mechanism. |
| `[WORLDBUILDING]` | Fictional or mythic canon designed for story, ritual theatre, games, art, or identity. |
| `[ARCHIVE-CLAIM]` | Preserved because a raw source asserted it; not independently verified. |
| `[RETIRED-PENDING-EVIDENCE]` | Kept in lineage but should not be repeated as a result until data and methods exist. |

Labels can combine. For example, the Seven-Phase cycle is `[SYMBOLIC] [IMPLEMENTED] [TESTABLE]`: symbolic meanings exist, software can model them, and behavioural usefulness could be tested. The “Hall of Timelines” is `[WORLDBUILDING] [SYMBOLIC]`, while a literal ability to access alternate timelines would be `[SPECULATIVE]` and presently unsupported.

## The preservation covenant

- Existing files remain untouched except for the root navigation link.
- Raw dialogue, mistakes, hype, contradictions, and abandoned formulations remain part of the lineage.
- New work goes in dated, standalone Markdown files.
- A claim can move upward only with evidence; it can move downward without being deleted.
- Mythic language is welcome when marked as mythic language.
- “Quantum,” “field,” “entropy,” “energy,” “resonance,” and “entanglement” must be defined locally. Metaphorical use must not borrow scientific authority.
- Simulated proxy scores must not be described as consciousness, qualia, sentience, or physical discovery.
- Personal spiritual practice must not substitute for medical or mental-health care.
- No compression without recovery: every synthesis must preserve its source path, disagreement, and failure lineage.

## Research posture

The atlas uses a four-step forge:

1. **Preserve** the original expression and source.
2. **Translate** it into plain language and explicit variables.
3. **Separate** literal, analogical, symbolic, and fictional readings.
4. **Test or build** the smallest version that can fail honestly.

The aim is not to make the raw archive respectable by sanding off its strangeness. The aim is to give each strange idea the form in which it can do its best work.

---

**Forge principle:** The light carried forward is not the claim that survived criticism. It is the clarity earned by letting the claim be tested.
