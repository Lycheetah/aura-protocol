## Quick Start

```bash
unzip cascade-living-os-frontier.zip
cd cascade-living-os
npm install
npm run dev
```

**Keyboard shortcuts:**
- `⌘K` — Command palette
- `ESC` — Close modals

**First steps:**
1. Go to Settings → Add API keys
2. Go to `/focus` → Start a focus session
3. Complete it → Watch μ fire
4. Check `/insights` for analytics
